# Evidencias requeridas

- auditoria.json: fuente, hashes, filas, columnas, clases, faltantes, duplicados y cruces.
- experimentos.csv: cuatro configuraciones, hipótesis, parámetros, commit, DVC, MLflow y métricas.
- seleccion.json: decisión basada exclusivamente en validación.
- metricas-test.json: evaluación final una sola vez sobre test.
- predicciones-test.csv: una fila por registro original.
- mlflow/: exportación estructurada de los cuatro runs.
- recuperacion/: entradas, salidas, hashes y logs en entorno nuevo.
